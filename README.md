# 📝 Keepho (키포)

**사진이 절대 사라지지 않는 바탕화면 메모 앱**

*Keep + Photo — 내 메모와 사진을 끝까지 지켜 주는 메모*

바탕화면에 붙여 두는 메모장이에요. 글과 사진을 자유롭게 적고, 창을 닫았다 열어도 모든 메모가 그대로 돌아와요.

> 현재 버전: **v0.4.0** · Windows용 · 개발 중

---

## 💡 왜 만들었나요?

기존 메모 앱에서 어느 날부터 사진을 붙여 넣으면 **"이미지를 로드할 수 없습니다"**가 뜨면서 사진이 보이지 않게 됐어요.
원인을 찾아보니 다른 프로그램이 윈도우의 사진 미리보기 기능을 건드려서, 메모 앱이 사진을 불러오지 못하고 있었어요.

키포는 이런 문제가 생길 수 없게 만들었어요.

- 사진을 **내 PC 폴더에 평범한 이미지 파일**로 저장해요
- 클라우드 동기화나 윈도우 미리보기 기능을 거치지 않아요
- 메모는 저장 도중 컴퓨터가 꺼져도 깨지지 않게 안전하게 저장해요
- 실수로 지운 메모도 휴지통에서 30일 동안 되살릴 수 있어요

## ✨ 기능

| 기능 | 설명 |
|---|---|
| 🗒️ 여러 개의 메모 | 바탕화면에 메모 창을 원하는 만큼 띄울 수 있어요 |
| 🖼️ 사진 넣기 | 붙여넣기(Ctrl+V), 끌어다 놓기, 🖼 버튼으로 사진 추가 |
| 🎨 색상 · 투명도 | 6가지 색 (노랑 · 초록 · 분홍 · 보라 · 파랑 · 회색) + 투명도 40~100% |
| 📌 항상 위에 | 다른 창보다 항상 위에 보이게 고정 |
| ✍️ 서식 | 굵게, 기울임, 밑줄, 취소선, 글머리 기호 |
| ☑ 체크리스트 | 할 일 목록을 만들고 네모 칸을 눌러 완료 표시 |
| 📸 화면 캡처 메모 | `Ctrl+Alt+S` → 화면 일부를 드래그하면 그 캡처가 바로 새 메모로 |
| 🔔 알림 | 달력과 시·분 버튼으로 몇 번의 클릭만으로 설정. 시간이 되면 메모가 맨 앞으로 나와 **확인을 누를 때까지** 깜빡이고 1분마다 알림음 |
| 🗑 휴지통 | 지운 메모를 30일 동안 보관, 언제든 복원 |
| ☰ 메모 목록 | 모든 메모를 한눈에 보고, 검색하고, 닫은 메모를 다시 열기 |
| 💾 자동 저장 | 글을 쓰는 즉시 저장, 위치·크기·색까지 기억 |

## 🚀 설치하고 실행하기

> 설치 파일(`Keepho-Setup-버전.exe`)을 만들 수 있어요: `npm run dist` → `dist` 폴더

**준비물:** [Node.js](https://nodejs.org) (LTS 버전), [Git](https://git-scm.com)

```bash
# 1. 코드 내려받기
git clone https://github.com/ppingppongcroo-svg/keepho.git
cd keepho

# 2. 필요한 부품 설치 (처음 한 번만)
npm install

# 3. 실행
npm start
```

## ⌨️ 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 새 메모 | ＋ 버튼 또는 `Ctrl+N` |
| 창 옮기기 | 메모 맨 위 막대를 잡고 끌기 |
| 버튼 보기 | 메모 위에 마우스를 올리기 |
| 사진 넣기 | `Ctrl+V`, 파일 끌어다 놓기, 또는 🖼 버튼 |
| 글머리 기호 | •≡ 버튼 또는 `Ctrl+Shift+L` |
| 체크리스트 | ☑ 버튼 또는 `Ctrl+Shift+C`, 네모 칸을 눌러 체크 |
| 화면 캡처 메모 | 어디서든 `Ctrl+Alt+S` 또는 메모 목록의 "화면 캡처" → 드래그 (Esc로 취소) |
| 색상 · 투명도 | 팔레트 아이콘 → 색 고르기, 슬라이더로 투명도 |
| 알림 설정 | 종 아이콘 → 빠른 설정 4개, 또는 달력 + 오전/오후 + 시·분 버튼 (1분 단위는 ▲▼) |
| 알림 끄기 | 울릴 때 [확인] 또는 [10분 뒤 다시] · 예약 취소는 알림 설정 창의 "알림 끄기" |
| 메모 닫기 | ✕ (메모는 지워지지 않고 목록에 남아요) |
| 메모 다시 열기 | ☰ 메모 목록에서 카드 누르기 |
| 메모 삭제 | 🗑 → 휴지통으로 (30일 동안 보관) |
| 메모 되살리기 | ☰ 메모 목록 → 휴지통 탭 → ↩ 복원 |

**메모가 저장되는 곳:** `%APPDATA%\Keepho\`
- `notes.json`: 메모 내용
- `images\`: 사진 파일

## 🧩 구조

[Electron](https://www.electronjs.org)으로 만들었어요. 웹 기술(HTML · CSS · JavaScript)로 윈도우 프로그램을 만드는 도구예요.

```
keepho/
├── main.js      본체: 창 만들기, 메모와 사진 저장
├── preload.js   창구: 화면이 본체에 부탁할 수 있는 일만 열어 둠 (보안)
├── note.html    메모 창 뼈대
├── note.js      메모 창 동작 (글쓰기, 사진, 버튼)
├── style.css    메모 창 모양
├── list.html    메모 목록 창 뼈대
├── list.js      메모 목록 동작 (검색, 열기, 삭제)
├── list.css     메모 목록 모양
├── capture.html 화면 캡처할 때 화면을 덮는 창
├── capture.js   캡처 영역 고르기 (드래그)
├── capture.css  캡처 창 모양
├── remind.html  알림 설정 창 뼈대
├── remind.js    알림 설정 동작 (빠른 설정, 달력, 시·분 고르기)
├── remind.css   알림 설정 창 모양
└── icons.js     앱 전체에서 쓰는 선 아이콘 모음
```
